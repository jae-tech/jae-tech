# 👋 Jaetech

기획부터 배포까지 전 과정을 직접 담당하는 풀스택 개발자입니다.  
실무 제약이 있는 기술과 아키텍처를 개인 프로젝트로 실험하며, AI를 활용한 효율적인 개발과 안정적인 인프라 설계를 추구합니다.  
서비스 개발을 넘어 운영 가능성과 자동화를 최우선으로 고려합니다.
